## Agent Relay 项目文档

本目录记录 Agent Relay 的架构、接口、安全边界、配置、部署、运行和测试规范。文档以仓库代码、配置、部署模板和测试为事实来源，只描述当前实现与明确的运行边界。

## 推荐阅读顺序

- 首次了解项目：先阅读根目录 [README](../README.md)，再阅读[架构设计](架构设计.md)和[安全模型](安全模型.md)。
- 准备本地运行：阅读[配置说明](配置说明.md)和[部署指南](部署指南.md)。
- 开发调用程序：阅读[接口说明](接口说明.md)，重点关注状态机、SSE 游标和错误语义。
- 负责上线与值守：阅读[运维手册](运维手册.md)和[测试指南](测试指南.md)。

## 文档维护约定

- 根 `README.md` 负责项目定位、主要能力和快速开始；主题文档负责详细设计、边界和验证方法。
- 接口、配置、状态、部署命令或安全边界变化时，应同步更新对应主题文档、`.env.example`、部署模板和测试。
- 并列信息使用短列表或表格；三个以上存在依赖关系的步骤才使用图示。
- 每个 Markdown 表格、图片或 Mermaid 图前应有自然引导语，说明图表表达的对象。
- Mermaid 使用兼容性较好的 `graph TD`、`graph LR` 或 `sequenceDiagram` 基础语法，不依赖新版布局与交互指令。
- 面向人工执行的 Shell 命令统一使用 `$ ` 前缀；脚本源码、命令输出、环境变量和续行不添加前缀。
- 提交前检查 Markdown 围栏、本地链接、Mermaid 语法和命令是否仍与当前实现一致。
